# WWWAnalys Project Prompt

## Контекст проекта

Ты работаешь с проектом **WWWAnalys** — веб-приложением для учета производственных анализов.

### Стек технологий
- **Бэкенд**: Python 3.9+, FastAPI, SQLAlchemy, PostgreSQL, JWT-аутентификация
- **Фронтенд**: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Tailwind CSS
- **DevOps**: Docker, Docker Compose

### Архитектура бэкенда
```
backend/app/
├── api/           # REST API маршруты
├── auth/          # Аутентификация (JWT)
├── core/          # Конфигурация и подключение БД
├── crud/          # CRUD операции (User, AnalysisType, ProcessLog)
├── models/        # SQLAlchemy модели (User, AnalysisType, Indicator, ProcessLog)
└── schemas/       # Pydantic валидационные схемы
```

### Основные компоненты

1. **Типы анализов** (AnalysisType)
   - Можно создавать разные типы анализов
   - Каждый тип содержит индикаторы (показатели)
   - Индикаторы имеют минимальное/максимальное значение

2. **Журнал процессов** (ProcessLog)
   - Записи о проведенных анализах
   - Связаны с типом анализа
   - Содержат значения показателей

3. **Пользователи** (User)
   - Регистрация и аутентификация
   - Роли: администратор, пользователь

### Запуск проекта

```bash
# Запустить все сервисы (PostgreSQL, backend, frontend)
docker-compose up -d

# Или локально
cd backend
source venv/bin/activate
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### API endpoints

- `POST /auth/register` — регистрация
- `POST /auth/login` — вход
- `GET/POST /analysis-types` — типы анализов
- `GET/POST /process-logs` — журнал процессов

### Docker образы

- `las84/wwwanalys-backend:latest` — образ бэкенда
- `las84/wwwanalys-frontend:latest` — образ фронтенда

## Рекомендации при работе

1. **При изменении моделей** — обнови соответствующие schemas и crud операции
2. **При добавлении API** — следуй паттерну в `/app/api/` папке
3. **При добавлении новых зависимостей** — добавь в `requirements.txt`
4. **При создании Docker образов** — используй кэширование слоев
5. **При работе с БД** — используй SQLAlchemy ORM, а не raw SQL
