# План создания проекта wwwanalys

## 1. Настройка проекта и структуры
   - Создание базовой структуры проекта wwwanalys
   - Настройка виртуального окружения
   - Создание requirements.txt с необходимыми зависимостями

## 2. Настройка базы данных в Docker
   - Создание docker-compose.yml для PostgreSQL
   - Настройка подключения к PostgreSQL
   - Создание моделей SQLAlchemy для:
     - Users (пользователи с ролями)
     - AnalysisTypes (типы анализов)
     - Indicators (показатели для каждого типа анализа)
     - ProcessLogs (журнал процессов)
     - IndicatorValues (значения показателей)

## 3. Реализация бэкенда (FastAPI)
   - Настройка подключения к Docker PostgreSQL
   - Создание эндпоинтов для аутентификации
   - Реализация CRUD операций для моделей
   - Настройка ролей пользователя (Администратор/Пользователь)
   - Создание API для управления типами анализов и показателями
   - Создание API для ввода значений показателей

## 4. Настройка фронтенда
   - Создание базовой структуры HTML/CSS с Tailwind
   - Разработка компонентов интерфейса
   - Реализация JavaScript для работы с API

## 5. Тестирование

   - Проверка функциональности
