# План развития системы показателей анализа

- [ ] Добавить поле `description` — подробное описание показателя
- [ ] Добавить поле `category` — категория показателя (качество, безопасность, производительность)

## Текущая архитектура (схема данных)

```
indicator_library (справочник показателей)
├── id
├── name
├── unit
├── data_type (number | text | select)
├── options (JSON для SELECT)
├── description        🆕
├── category           🆕
├── is_required        🆕
├── default_value      🆕
├── validation_rules   🆕
├── created_by         🆕
└── created_at

template_indicators (связь шаблонов с показателями)
├── id
├── template_id → analysis_types.id
├── indicator_id → indicator_library.id
├── min_value
├── max_value
├── sort_order
├── is_custom           🆕
└── template_notes      🆕

indicators (старая модель — прямая связь с AnalysisType)
├── id
├── name
├── unit
├── min_value
├── max_value
├── data_type
├── options
├── analysis_type_id → analysis_types.id
└── values → IndicatorValue
